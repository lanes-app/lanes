# Lanes

**Terminal-Cockpit für Agenten-Workflows auf Windows.**

Lanes ist für alle gebaut, die mit Claude Code und anderen CLI-Agenten in vielen Terminals
gleichzeitig arbeiten: ein Projekt pro Tab, bis zu sechs Terminals als Splits, ein Orchestrator-Terminal
pro Projekt, Agenten-Status mit Benachrichtigung, sobald ein Agent auf dich wartet.

## Download

Neueste Version: **[Lanes-Setup.exe](https://github.com/lanes-app/lanes/releases/latest/download/Lanes-Setup.exe)**
(Windows 10/11, 64-bit, kostenlos). Alle Versionen unter [Releases](https://github.com/lanes-app/lanes/releases).

Hinweis: Lanes ist noch nicht signiert. Windows SmartScreen zeigt beim ersten Start einen Hinweis;
über "Weitere Informationen › Trotzdem ausführen" geht es weiter.

## Funktionen

- Projekte als Tabs, Terminals als Splits (1 / 2–3 Spalten / 2×2 / 3×2)
- Orchestrator-Terminal mit Krone, Agenten-Status (arbeitet · wartet · fertig), Benachrichtigungen
- Claude-Sessions fortsetzen, Orchestrator-MCP für Claude Code, Git-Worktrees, Sicherungspunkte
- Prompts und Broadcast, Hooks, Todos, Dashboard, Kommandopalette (Strg+K)
- Handy-Fernzugriff im lokalen Netz und Discord Rich Presence, beides Opt-in
- Hell- und Dunkelmodus, wählbare Akzentfarbe
